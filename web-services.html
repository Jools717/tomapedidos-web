Introducción 

        La plataforma Toma Pedidos permite la integración con software de terceros a través de Webservices REST 

        Para usar la plataforma cada cliente recibe:
        URL BASE: Coresponde a la url de acceso al sistema. Ejemplo: https://tp4.comtor.net/miempresa/
        usuario:  Creado desde el modulo de usuarios.
        contraseña: Creado desde el modulo de usuarios.

        Las transacciones necesitan un token de autenticación que debe enviarse como encabezado en la transacción. La llave del encabezado es Auth-Token
        El token se obtiene llamando el Webservice de login.

webservices:

Login POST: /webservices/io/login

Descripción 

            Se envía en JSON el usuario y la contraseña así:

Request 

            {
              "username"  : "pepe",
              "password" : "ConTr4seNa"
